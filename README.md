# 動画投稿シミュレーター

`index.html` だけで動く、シンプルな動画投稿シミュレーションアプリです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 登録者数と合計視聴回数を入力します。
3. 動画タイトルと内容を入力します。
4. 「動画を追加」を押すと、動画とコメント欄が表示されます。

## AIコメントについて

- OpenAI APIキーを入力すると、ブラウザからOpenAI APIにリクエストしてコメントを生成します。
- APIキーを入力しない場合やAPI通信に失敗した場合は、HTML内のデモコメントを生成します。
- APIキーはブラウザに保存していません。本格公開する場合は、APIキーを隠すためにサーバー経由で呼び出してください。
